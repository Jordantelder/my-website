# Knowledge folder

Drop `.md`, `.txt`, or `.pdf` files here (sub-folders are fine). The server indexes new and
changed files when it starts and whenever you run `voicebox sync` or call `POST /knowledge/sync`.
Notes you dictate ("remember that ...") or add from the phone page are written to `notes/` as
Markdown files, so everything the assistant knows is a file you can read, edit, or delete.
